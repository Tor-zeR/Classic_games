# Controls

## Tetris

| Action | Keys |
|--------|------|
| Move left / right | `← →` |
| Rotate | `↑` or `Z` |
| Soft drop | `↓` |
| Hard drop | `Space` |
| Pause | `P` or `Esc` |

**Mobile:** Swipe left/right to move, swipe up to rotate, swipe down to drop.

---

## Pac-Man

| Action | Keys |
|--------|------|
| Move | `↑ ↓ ← →` |
| Pause | `P` or `Esc` |

**Mobile:** Swipe in the direction you want to move.

---

## Space Invaders

| Action | Keys |
|--------|------|
| Move | `← →` |
| Shoot | `Space` |
| Pause | `P` |

**Mobile:** D-pad to move, fire button to shoot.

---

## Snake

| Action | Keys |
|--------|------|
| Move | `↑ ↓ ← →` or `WASD` |
| Shoot (when powered) | `Space` |
| Pause | `P` or `Esc` |

**Mobile:** Swipe anywhere on the game canvas.

---

## Berzerk

| Action | Keys |
|--------|------|
| Move | `↑ ↓ ← →` or `WASD` |
| Shoot | `Space` |
| Aim (8 directions) | Hold movement key while shooting |
| Pause | `P` |

**Mobile:** D-pad (8-directional), fire button.

---

## Lode Runner

| Action | Keys |
|--------|------|
| Move / Climb | `↑ ↓ ← →` or `WASD` |
| Dig left | `Z` |
| Dig right | `X` |
| Pause | `P` or `Esc` |
| Restart level | `R` |

**Mobile:** D-pad to move, dedicated dig-left / dig-right buttons.

---

## Xonix

| Action | Keys |
|--------|------|
| Move | `↑ ↓ ← →` |
| Pause | `P` |

**Mobile:** D-pad.

---

## Paratrooper

| Action | Keys |
|--------|------|
| Rotate cannon left | `← ` |
| Rotate cannon right | `→` |
| Shoot | `Space` |
| Pause | `P` |

**Mobile:** D-pad left/right, fire button.

---

## Global

| Action | Keys |
|--------|------|
