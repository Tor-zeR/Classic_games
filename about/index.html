About Classic Arcade

Classic Arcade is a free, fan-made browser game collection celebrating the golden age of arcade gaming — the era of blinking CRT monitors, glowing joysticks, and the eternal challenge of beating the high score. Every game here is a passion project built to run instantly in your browser with no downloads, no accounts, and no fees.

What We Offer

Classic Arcade currently hosts 9 free classic arcade games, each reimagined with a neon synthwave visual style while faithfully preserving the gameplay mechanics that made the originals legendary:

  • Tetrix — falling-block puzzle game inspired by Tetris (1984)
  • Chomp — maze-chase game inspired by Pac-Man (1980)
  • Alien Wave — space shooter inspired by Space Invaders (1978)
  • Neon Serpent — survival game inspired by Snake (1976–1997)
  • Robo Maze — maze shooter inspired by Berzerk (1980)
  • Gold Rush — action puzzle game inspired by Lode Runner (1983)
  • Territory — territory capture game inspired by Xonix/Qix (1981)
  • Airborne — turret defense game inspired by Paratrooper (1982)
  • Highway Delivery — top-down racer inspired by Road Fighter (1984)

Technology

Every game is written in pure HTML5, JavaScript, and CSS — no external game engines, no plugins, no Flash. They run at 60fps on modern desktop and mobile browsers via the HTML5 Canvas API.

RenderingHTML5 Canvas API at 60fps
AudioWeb Audio API — synthwave chiptunes
InputKeyboard, touch, and gamepad support
OfflineService Worker PWA — play without internet
PerformanceNo frameworks, no dependencies
PrivacyNo tracking, no cookies, no data collection
