# Snake Game: Controls Summary

## PC Keyboard (Primary Controls)
Use either set — both work simultaneously:

| Direction | Arrow Keys | WASD Keys |
|-----------|------------|-----------|
| **Up**    | `↑`        | `W`       |
| **Down**  | `↓`        | `S`       |
| **Left**  | `←`        | `A`       |
| **Right** | `→`        | `D`       |

**Key Rules:**
- Direction changes only between movement ticks
- 180° reversal is **blocked** (e.g. Right → Left instantly is ignored)
- Works on any standard PC keyboard

## Mobile / Touch-Screen (Optional Controls)
Automatic detection on touch devices. Swipes map directly to keyboard actions:

| Keyboard Action | Touch Gesture     |
|-----------------|-------------------|
| Left (`←`)      | Swipe Left        |
| Right (`→`)     | Swipe Right       |
| Up (`↑`)        | Swipe Up          |
| Down (`↓`)      | Swipe Down        |

**Touch Rules:**
- Swipe anywhere on the game screen
- Minimum swipe distance: ~40 px
- 180° reversal still blocked
- Works alongside Bluetooth keyboard if connected
